# Capyra Site UI Kit

Marketing site (`apps/site`) — bilingual PT-BR/EN, Next.js + Tailwind.

## Components
- `SiteHeader.jsx` — sticky header with logo, nav pills, language switcher, CTA
- `SiteFooter.jsx` — footer with logo lockup, nav links, CTA
- `HeroSection.jsx` — full hero with mascot visual and metric chips
- `MarketingComponents.jsx` — FeatureCard, Section, AudienceCard, PlatformCoverage, DashboardMock, FaqAccordion

## index.html
Full interactive landing page click-thru (home → product pages).

## Design
- Fonts: Kanit (display) + IBM Plex Sans (body)
- Palette: warm cream canvas, navy headings, brand blue CTAs
- Cards: rounded-3xl, warm borders, shadow-sm
- CTAs: rounded-full, brand blue with shadow-glow
- Body gradient + dot grid texture
