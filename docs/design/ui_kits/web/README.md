# Capyra Web UI Kit

Authenticated app (`apps/web`) — Next.js App Router + shadcn/ui.

## Components
- `AppShell.jsx` — dark navy sidebar + inset main content area
- `DashboardView.jsx` — evidence ledger dashboard with status cards and activity rows
- `AnalysesView.jsx` — history list with search/filter

## index.html
Full interactive prototype: sidebar navigation, dashboard, analyses list.

## Design
- Fonts: Kanit (display) + IBM Plex Sans (body)
- Sidebar: dark navy hsl(212 71% 23%), warm cream text
- Main: warm cream canvas hsl(38 52% 96%)
- Cards: rounded-[1.75rem], warm border, shadow-sm
- Body gradient: radial brand blue + accent + linear
- Dot grid texture (fixed)
- Dark mode supported
