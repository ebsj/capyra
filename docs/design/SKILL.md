Use the requested output format and existing product surface.

- For brand voice, palette, typography or approved assets, consult the relevant
  section of [README.md](README.md) or [tokens](colors_and_type.css).
- For marketing UI, read [site.md](site.md).
- For authenticated product UI, read [web.md](web.md).
- For prototypes, consult the relevant [site kit](ui_kits/site/README.md) or
  [web kit](ui_kits/web/README.md) only when reusable examples are useful.

Reuse approved assets from `assets/` when needed by the deliverable. A production
UI request stays in production code; create standalone HTML only when it suits
what the user asked for. Resolve missing design choices from the task and
existing UI, asking only when a material choice remains unclear.
