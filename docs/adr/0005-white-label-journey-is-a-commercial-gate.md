# White-label journey is a commercial gate

A network is not sold until a practical **Gate white label** passes: in connection, consent, selection, callback, reconnect, revoke, errors, email, the authorized-apps list and the published post, the operator can identify only Capyra and that network. Vendor docs are not evidence. Headless OAuth is necessary and not sufficient — the network's own consent screen must not name the vendor either.

Shipping behind a rebranded vendor dashboard would be days of work and would fail this bar. We accept slower delivery and a per-network go/no-go rather than a partial white label.
