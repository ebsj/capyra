# Publicações têm destinos independentes

Uma publicação agrupa o conteúdo de uma marca, enquanto cada conta social
selecionada forma um destino com variação, agendamento e estado próprios. Cada
envio ou repetição é registrado como uma tentativa de entrega; o estado geral
da publicação é derivado dos destinos, permitindo repetir somente falhas sem
alterar ou duplicar entregas concluídas.
